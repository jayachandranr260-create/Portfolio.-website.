# My Personal Portfolio Website

A simple personal portfolio website built using **HTML** and **basic CSS**.  
It includes a home page and a contact page to introduce myself and share ways to get in touch.

## Pages

- **Home** – Introduction, brief information about me, and my skills.
- **Contact** – Contact details and links to connect with me.

## Features

- Clean and simple design
- Easy navigation between pages
- Responsive layout
- Built using only HTML and CSS

## Technologies Used

- CSS3
